# Domain Docs

This is a single-context repository.

## Before exploring

- Read the root `CONTEXT.md`.
- Read ADRs under `docs/adr/` that affect the area being changed.
- If either location is absent, proceed silently.

## Vocabulary

Use canonical terms from `CONTEXT.md` in issues, proposals, tests, and code. Avoid synonyms the glossary rejects.

If a required concept is missing, reconsider whether it belongs to the domain or note the gap for domain modeling.

## ADR conflicts

Surface conflicts with existing ADRs explicitly rather than silently overriding them.
